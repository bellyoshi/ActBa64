# ProjectEditor 仕様

`src/projecteditor` の MDI エディタ（`ProjectEditor.exe`）の現行仕様です。言語は [language.md](./language.md)、ビルドと配布物は [build.md](./build.md)。キーワード解説の HTML は [src/projecteditor/help/actba64_ref.html](../src/projecteditor/help/actba64_ref.html) です。

エディタ自身は 64bit GUI です。ユーザーのソースを 32bit / 64bit のどちらに訳すかは、隣に置く `actba64.exe` の起動オプションで切り替えます。

## 1. 起動

引数なしでは空の `untitled` を 1 枚開きます。第 1 引数が実在するファイルならそれを開きます。相対パスは、そのまま見つからなければ exe のあるディレクトリ基準で探します。

| 引数 | 動作 |
|---|---|
| なし | `untitled`（UTF-8、BOM なし） |
| `*.pj` | プロジェクトウィンドウだけ開く。ソースは開かない |
| それ以外のファイル | そのファイルをソース子ウィンドウで開く |
| ディレクトリ、または見つからないパス | 引数なしと同じ |

ファイルのドロップも同じです。複数ドロップしたときは先頭の 1 件だけ開きます。

## 2. ウィンドウ

フレームのクライアントは MDI です。ソースは子ウィンドウで、同時に **最大 8 枚**です。9 枚目の新規作成・開くは何もしません。

プロジェクトウィンドウは別クラスの MDI 子で、8 枚の枠を使いません。**Window** メニューは Cascade / Tile Horizontal / Tile Vertical です。MDI 標準の Ctrl+F4（子を閉じる）、Ctrl+Tab / Ctrl+F6（子の切り替え）は有効です。

未保存の変更（タイトルの `*`）がある子を閉じるときは、「保存しますか？」（はい / いいえ / キャンセル）と尋ねます。フレームを閉じるときと、表示言語を変えて再起動するときは、未保存の子を順に前面に出して尋ねます。はいは上書き保存（パスが無ければ名前を付けて保存）で、保存できなかったときとキャンセルでは閉じません。プロジェクトウィンドウを閉じると、開いているプロジェクトは解除されます。一時フォルダーの新しいプロジェクト（[12. フォームデザイナ](#12-フォームデザイナ)）は、終了・再起動・プロジェクトウィンドウを閉じる・別の `.pj` を開くときに、先に「新しいプロジェクトはまだ一時フォルダーにあります。保存しますか？」と尋ねます。

子ウィンドウとフレームのタイトルは同じです。

```text
editor - (untitled) [64bit, UTF-8]
editor - C:\work\hello.sbp [32bit, Shift-JIS] *
```

`*` は未保存です。保存したあと Undo で内容が戻っても、`*` は付いたままです。

`[64bit]` / `[32bit]` は出力先（Basic メニューの選択。`-actba32` を付けるかどうか）で、メニューで選び直すとすぐ変わります。N88BASIC構文(-pN88) を入れると `[64bit, N88BASIC, UTF-8]` のように付き、`-pN88` を付けて訳します（32bit / 64bit とは別に入り切りし、`editor.target` に覚えます）。ActiveBasic2構文(-pAB2) を入れると `[64bit, AB2, UTF-8]` のように付き、`-pAB2` を付けて訳します。N88BASIC構文と ActiveBasic2構文は同時には入らず、片方を入れるともう片方は外れます。「使用していない命令を削除(-X)」を入れると `[64bit, -X, UTF-8]` のように付き、`-X` を付けて訳します（呼ばれない関数を exe に入れないので小さくなる。ほかの項目とは別に入り切りし、`editor.target` の最後に ` x` を付けて覚えます）。

プロジェクトを開いていない文書が新規作成でまだ一度も保存していない（無題の）ときは、どの構文でも、実行・コンパイルは今の内容を `%TEMP%\ActBa64Temp\untitled.abp` に書いて訳します（exe も同じフォルダーにできます）。保存先は、上書き保存・名前を付けて保存か、閉じるときの「はい」で尋ねます。ファイルのある文書は、いつもどおり保存してから訳します。文書そのものは保存しないので、閉じるときの保存確認はそのまま出ます。診断の一時ファイル名は文書のパスに置き換えるので、クリックで文書の行へ飛べます。文書を開いていないときのフレームは `editor [64bit]`、プロジェクトを開いていれば `editor - C:\work\p.pj [32bit]` です。

編集対象は前面のソースです。プロジェクトウィンドウを前面にしても、直前のソースが編集対象のまま残ります。

## 3. メニュー

既定の表示は英語です。`Language=ja` のときの見出しは次のとおりです（括弧内はニーモニック）。ソース子にフォーカスがあるとき、次の Ctrl キーが使えます。

| キー | 動作 |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | コピー / 切り取り / 貼り付け |
| Ctrl+A | すべて選択 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+S | 上書き保存 |
| Ctrl+F | 検索 |
| F3 | 次を検索 |
| Shift+F3 | 前を検索 |

| メニュー | 項目 |
|---|---|
| ファイル(&F) | 新規(&N) / 新しいフォーム(&M)（N88BASIC構文・ActiveBasic2構文のときは灰色） / AB4プロジェクト作成(&P)...（Windows 版だけ。[§7.2](#72-ab4-プロジェクト作成と-projectcmd)） / 開く(&O) / 名前を付けて保存(&A) / 上書き保存(&S) |
| 編集(&E) | 元に戻す(&U) / やり直し(&R) / 切り取り(&T) / コピー(&C) / 貼り付け(&P) / すべて選択(&A) / 削除(&D) / 検索(&F) / 次を検索(&N) / 前を検索(&V) |
| 表示(&V) | プロジェクトビュー(&P)（プロジェクトの窓を出す・隠す。出ていればチェック。隠してもプロジェクトは閉じない。プロジェクトが無いときは灰色） |
| Basic | 64bit / 32bit（チェック） / N88BASIC構文(-pN88)（チェック） / ActiveBasic2構文(-pAB2)（チェック。-pN88 と同時には入らない） / 実行(&R) / 実行（終了後に待機）(&W) / コンパイル(&C) |
| 設定(&S) | 設定 |
| ヘルプ(&H) | キーワード / actba64 ヘルプ |
| ウィンドウ(&W) | 重ねて表示(&C) / 上下に並べる(&H) / 左右に並べる(&V) |

編集メニューは、ソース子が 1 枚もないときは動きません。右クリックメニューは、元に戻す、切り取り、コピー、貼り付け（クリップボードが空なら無効）、削除、すべて選択、actba64 ヘルプです。キャレット位置に識別子があるときだけ「キーワードのヘルプ」を足します。やり直しは右クリックにはありません。

ファイルダイアログのフィルタは `Source (*.abp;*.sbp;*.bas)`、`Project (*.pj)`、`All (*.*)` です。名前を付けて保存の既定拡張子は `abp`（メインのコード。`#include` で読む部品は `.sbp`）で、上書き前に確認します。パスが空の上書き保存は、名前を付けて保存になります。

## 4. 編集

内部テキストは UTF-8 のギャップバッファです。キャレットは UTF-8 の 1 文字ずつ動きます。

| 操作 | 動作 |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+A / Ctrl+Z / Ctrl+Y / Ctrl+S | メニューの同名操作 |
| 文字入力 | 挿入。選択中なら選択範囲を置き換える |
| Enter | LF（`0A`）を挿入する。CR は付けない |
| Backspace | 直前の 1 文字を消す |
| Delete | 選択範囲、なければ次の 1 文字を消す |
| 左右上下 | 1 文字、または 1 行。Shift なしでは選択を解除する |
| Shift+左右上下 | 起点から 1 文字、または 1 行ずつ選択を伸ばす・縮める |
| Page Up / Page Down | 表示行数だけスクロールする。キャレットは動かない |
| ホイール | 3 行スクロール |
| クリック | その位置へキャレットを移し、選択を解除する |
| Shift+クリック | 起点からその位置までを選択する。ドラッグ中も起点は変えない |
| ドラッグ | 押した位置から離した位置までを選択する。窓の外では 1 行ずつ送る |
| F1 | キャレット位置のキーワードヘルプ |
| F12 | フォームデザイナとの切り替え。`.wnd` では AB4 デザイナー（[12. フォームデザイナ](#12-フォームデザイナ)） |
| Tab / Home / End | 未対応 |

行の区切りは CR、LF、CRLF です。既存ファイルの改行バイトはそのまま残し、Enter で足した行だけ LF です。

**検索** は前面のソースだけが対象です。Ctrl+F でダイアログを開き、検索語、大文字小文字の区別（既定は区別する）、次を検索、前を検索、閉じるを出します。Enter は次を検索、Esc は閉じるです。F3 と Shift+F3 は、ダイアログを開かずに直前の検索語で次と前を探します。検索語がまだ無いときはダイアログを開きます。

次を検索は、選択があればその終端、無ければキャレットから後ろへ進みます。前を検索は、選択があればその始端、無ければキャレットの直前から前へ戻ります。文書の端まで来たら先頭または末尾へ 1 周します。一致した範囲を選択し、その末尾が見える位置までスクロールします。空の検索語は何もしません。見つからなければメッセージを出して選択は変えません。ソース子が無いときは動きません。置換はしません。

選択範囲は、ドラッグ、Shift を押したままの移動またはクリック、**すべて選択** で作ります。起点は、選択が無ければその操作の前のキャレットです。選択が無いときのコピーと切り取りは、文書全体が対象です。切り取りで選択が無いときは文書を空にします。貼り付けは Unicode テキストを優先し、無ければ CP932 のテキストとして読みます。

Undo は全文スナップショットで、最大 **64** 段です。入力は 1 文字ずつ 1 段になります。貼り付け・切り取り・削除は 1 操作で 1 段です。別の子へ切り替えると、その子の Undo は初期化されます（開いた直後の全文が最初の 1 段）。

IME の変換中文字列はキャレット位置に重ねて表示し、確定した文字列を UTF-8 で挿入します。変換ウィンドウはキャレット位置に合わせます。

## 5. 文字コード

開いたファイルの判定は次の順です。

1. 先頭が `EF BB BF` なら UTF-8 BOM
2. 全体が妥当な UTF-8 なら UTF-8
3. それ以外は Shift_JIS（CP932）

新規文書は UTF-8（BOM なし）です。保存は開いたときの符号のまま書き戻します。UTF-8 BOM は BOM を付けて書き、CP932 は UTF-8 バッファから CP932 へ変換します。タイトルの符号名は `UTF-8` / `UTF-8 BOM` / `Shift-JIS` です。符号を選ぶ UI はありません。

## 6. プロジェクト

`.pj` を開くと（ファイル → 開く、ドロップ、起動引数）、ソースは開かずプロジェクトウィンドウが出ます。別の `.pj` を開くと一覧が差し替わります。見本は [`src/actba64/samples/mdi/mdi.pj`](../src/actba64/samples/mdi/mdi.pj) です。

`#SOURCE` の次の行から、次に `#` で始まる行の手前までを一覧します。空行と `'` コメントは除きます。最大 **128** 件で、超えた分は無視します。

プロジェクトウィンドウはツリー（TreeView）です。ルートに `.pj` のファイル名を置き、その下に `#SOURCE` のファイルを書いた順に並べます。相対パスにフォルダーがあれば（`..\common\TextEnc.abp` など）、最後の区切りの手前まで（`..\common`）を 1 つのフォルダーのノードにして、その下にファイル名を置きます。同じフォルダーかどうかは、区切りの `\` と `/`、英字の大小を区別せずに比べます。ノードはすべて開いた状態で出ます。日本語のファイル名もそのまま出ます（UTF-16 で渡す）。ファイルのノードを選ぶと（クリック・矢印キー）そのファイルを開き、既に開いていれば前面にします。ルートとフォルダーのノードを選んでも何もしません。`.pj` と同じフォルダーにウィンドウ定義ファイル `<.pj の名前>.wnd` があれば、`<.pj の名前>.abp` のノードの下にぶら下げます（その `.abp` が `#SOURCE` に無ければルートの末尾）。選ぶと `.wnd` を文書として開きます。実装は `src/projecteditor/ProjTree.sbp`（パスの分け方は `ProjTreeText.sbp`）です。Linux 版は自前で描くリストのままです（[§14](#14-linux-版)）。

パスの結合は `.pj` のあるディレクトリ基準です。`\` または `/` で始まるパスと、2 文字目が `:` のパスはそのまま使います。同じファイルかどうかは、区切りを `\` に揃え、英字の大小を無視して比べます。

プロジェクトから読む指令は次の 2 つだけです。比較は大小を区別しません。

| 指令 | 用途 |
|---|---|
| `#OUTPUT_RELEASE` | コンパイル出力。無ければ `.pj` の拡張子を `.exe` にしたもの |
| `#USEWINDOW` | 実行時にコンソールを残すか。値は 10 進整数。未指定と `0` はコンソール、`1` 以上は exe を直接起動。`1` で `<名前>.wnd` があれば、コンパイルの前に `Callback.wbp` / `MakeWindow.wbp` を作る（[§7.1](#71-ab4-互換の-radusewindow1)） |

`#SOURCE` の外でも、この 2 つはファイル全体から読みます。

## 7. コンパイルと実行

Basic の **64bit**（既定）と **32bit** は排他です。選択は exe と同じディレクトリの `editor.target` に `64` または `32` と保存します。ファイルが無い、または先頭 2 バイトが `32` でないときは 64bit です。

`.pj` を開いたときは、その `#PLATFORM` に合わせます（`32` なら 32bit、`64` なら 64bit。書かれていなければそのまま）。プロジェクトを開いているあいだにメニューで選び直すと、`.pj` の `#PLATFORM=` 行をその値に書き換えます（文字コードと改行はそのまま。行が無ければ `#SOURCE` の前に足す）。`actba64` 自身は `#PLATFORM` を読みません。

コンパイラは exe と同じディレクトリの `actba64.exe` です。そこにファイルが無いときは起動せず、メッセージウィンドウに見つからない旨を出します。

呼び方は次です。パスに空白があるときだけ、その引数を二重引用符で囲みます。

```text
actba64 <入力> -o <出力>
actba64 -actba32 <入力> -o <出力>
```

| 状態 | 入力 | 出力 |
|---|---|---|
| プロジェクトが開いている | その `.pj` | `#OUTPUT_RELEASE`（`.pj` のあるディレクトリ基準）。無ければ `.pj` の拡張子を `.exe` にしたもの |
| プロジェクトを開いていない | 前面のソース 1 ファイル | そのパスの拡張子を `.exe` にしたもの |

プロジェクトを開いているあいだは、前面が別ファイルでも Compile / Run はその `.pj` を渡します。

コンパイル前に保存します。失敗したらコンパイルしません。

- プロジェクト: 開いているメンバーのうち、前面のファイルと、未保存のファイル。メンバーでないファイルは保存しない
- 単体: 前面のファイル。無題なら保存せず、`%TEMP%\ActBa64Temp\untitled.abp` に書いて訳す
- 一時フォルダーの新しいプロジェクト: 一時フォルダーのメンバーに書くだけで、保存先は尋ねない

標準出力と標準エラーをまとめてメッセージウィンドウへ出します。末尾に `Compile succeeded.` または `Compile failed. (exit=N)` を足します。コンパイラが無言で成功したときは `Compile succeeded.` だけ、失敗で無言のときは `Compile failed. (exit=N)` だけです。

**実行** はコンパイルが終了コード 0 のあと起動します。起動できなければ `Failed to run program.` を足します。**実行（終了後に待機）** も同じ手順でコンパイルしたあと、`#USEWINDOW` と `#console` に関係なく `cmd /k "<exe>"` で起動し、終了後もコンソールを残します。どちらも作業ディレクトリは exe のあるフォルダなので、`date1.txt` のような相対パスは exe の隣のファイルを開きます。

| 状態 | 起動 |
|---|---|
| プロジェクトで `#USEWINDOW` が 0（未指定も同じ） | `cmd /k "<exe>"` |
| プロジェクトで `#USEWINDOW` が 1 以上 | exe を直接起動 |
| 単体で、先頭 120 行のいずれかの行頭が `#console` | `cmd /k "<exe>"` |
| それ以外の単体 | exe を直接起動 |

単体の `#console` は、行頭の空白とタブを除いた先頭 8 文字が `#console` と一致するときだけです。大小は区別します。

### 7.1 AB4 互換の RAD（#USEWINDOW=1）

AB 4.20 の ProjectEditor で作ったウィンドウのプロジェクトを、そのままコンパイルできます。`.pj` が `#USEWINDOW=1` で、`.pj` と同じフォルダに `<.pj の名前>.wnd` があるときは、コンパイルの前にエディタの隣の `ProjectCmd -regen <.pj>`（[§7.2](#72-ab4-プロジェクト作成と-projectcmd)）を呼び、その `.wnd` から `Callback.wbp` と `MakeWindow.wbp` を作り直します。生成はエディタではなく ProjectCmd が受け持ちます。ProjectCmd が無いとき・失敗したときはコンパイルしません。AB 4.20 と同じく毎回上書きするので、この 2 つは手で直さないでください。メッセージウィンドウには `Generated Callback.wbp and MakeWindow.wbp from <.wnd>` と出ます。`.wnd` が無いとき（`Form` クラスで窓を作るプロジェクトなど）は何もしません。`.wnd` が読めないときや書けないときはコンパイルしません。

[§12](#12-フォームデザイナ) のフォームデザイナ（`Form` クラスの `InitializeComponent`）とは別物です。`.wnd` を編集する画面はありません。

書く中身は AB 4.20 の出力と同じです。AB 4.20 の Samples（CDPlayer / Downloader / Puzzle / SystemWatcher / TextEditor / Driving）と、AB 4.20 で作った小さなプロジェクトで、バイト単位で一致することを確かめています。古い版で書かれた Samples の一部には、モーダル ダイアログが無いのに `DialogBox` の中に `Else` から始まる行が入っています。ActBa64 は今の AB 4.20 と同じく中身を空にします。

- 文字コードは `.wnd` と同じです（AB 4.20 の `.wnd` は Shift_JIS。英数字だけの `.wnd` も Shift_JIS で書きます）。改行は CRLF です
- 部品の名前とメニューの ID に 1000 から番号を振って `Const` にします。名前が同じものは 1 回だけです
- 窓ごとに `EventCall_<窓>` を作ります。`.wnd` の `FILEPATH` のソースに書いてあるイベント プロシージャだけを、書いてある順に呼びます。`WM_DESTROY` が先頭で、ダイアログでは `WM_INITDIALOG` が先頭です。その後に `WM_CLOSE`、`WM_NOTIFY`、`WM_COMMAND` が続きます
- `MakeWindow.wbp` と `DialogBox` が登録する窓のプロシージャは `CALLBACK` の関数です。その関数が `#SOURCE` のどのファイルにも無ければ `EventCall_<窓>` にします（AB 4.20 は `FILEPATH` のファイルだけを見ます）
- `#OPTION` に `&H2` があれば、先頭で `InitCommonControlsEx` を呼びます
- `TYPE` は 0 がノーマル ウィンドウ（`MakeWindow.wbp` で作る）、1 がモーダル ダイアログ（`DialogBox`）、2 がモードレス ダイアログ（`CreateDialog`）です

イベント プロシージャの名前は `窓_イベント`、`窓_部品_イベント`、`窓_メニューID_MenuClick` です。大小は区別しません。

| 種類 | イベント |
|---|---|
| 窓 | `Activate` `Create` `Destroy` `DropFiles` `HScroll` `VScroll` `KeyDown` `KeyPress` `KeyUp` `LButtonDown` `LButtonUp` `LButtonDblClick`（M / R も）`MouseMove` `Move` `Resize` `Paint` `QueryClose` `SetFocus` `Timer` `MciNotify` `Notify` |
| Button / CheckBox / RadioButton | `Click` `DblClick` |
| Static / ImageBox | `Click` `DblClick` |
| EditBox | `Change` `ErrSpace` `HScroll` `KillFocus` `MaxText` `SetFocus` `Update` `VScroll` |
| ComboBox | `CloseUp` `DblClick` `DropDown` `EditChange` `EditUpdate` `ErrSpace` `KillFocus` `SelChange` `SelEndCancel` `SelEndOk` `SetFocus` |

### 7.2 AB4 プロジェクト作成と ProjectCmd

ファイル → AB4プロジェクト作成 で、AB 4.20 の「プロジェクトを作成」と同じ形のダイアログが出ます（Windows 版だけ）。

- プロジェクト名: 英字・数字・`_`（先頭は数字以外）で 64 文字まで。`<名前>_DestroyObjects` などの識別子になるためです
- ディレクトリ: 既定はデスクトップ（2 回目からは前に作ったところ）。参照でフォルダーを選べます。ここに `<名前>` のフォルダーを作ります
- アプリケーション タイプ: 6 種類を出しますが、いま作れるのは「EXE - ノーマル ウィンドウ ベース」だけです。ほかを選ぶと説明に「まだ作れません」と出て、作成ボタンが灰色になります
- "Hello world!" 表示: 入れると `MainWnd.sbp` に `MainWnd_Paint` を足し、窓に `Hello world!` を書きます

作成すると `ProjectCmd -createPj` を呼んで `<ディレクトリ>\<名前>\` に次を Shift_JIS・CRLF で書き、その `.pj` を開いて `MainWnd.sbp` を出します。`<名前>.pj` がもうあるときは作りません。

| ファイル | 中身 |
|---|---|
| `<名前>.pj` | `#USEWINDOW=1`、`#PLATFORM=32`、`#SOURCE` に `<名前>.abp` と `MainWnd.sbp` |
| `<名前>.abp` | `<名前>.idx` を読み、メッセージループを回す |
| `<名前>.idx` | `Callback.wbp`、`MainWnd.sbp`、`MakeWindow.wbp` を `#include` |
| `<名前>.wnd` | 480×360 の `MainWnd`（`CALLBACK = MainWndProc`） |
| `MainWnd.sbp` | `MainWndProc` と `MainWnd_Destroy` |
| `<名前>.wrk` | AB 4.20 の作業状態 |
| `Callback.wbp` / `MakeWindow.wbp` | [§7.1](#71-ab4-互換の-radusewindow1) と同じ生成器で作ったもの |

中身は AB 4.20 で作ったノーマル ウィンドウ ベースのプロジェクトとバイト単位で同じです。

同じものをコマンドラインで作るのが `ProjectCmd.exe`（`src/projecteditor/ProjectCmd.pj`）です。

```
ProjectCmd -createPj <名前> [-normalWnd] [-dir <フォルダー>] [-hello]
ProjectCmd -regen <プロジェクト.pj>
```

| オプション | 意味 |
|---|---|
| `-createPj <名前>` | `<フォルダー>\<名前>\` にプロジェクトを作る |
| `-normalWnd` | EXE - ノーマル ウィンドウ ベース（既定。`-nomalWnd` も同じ） |
| `-dir <フォルダー>` | 作る場所。既定は今のフォルダー |
| `-hello` | 窓に `Hello world!` を書く |
| `-regen <.pj>` | `<.pj の名前>.wnd` から `Callback.wbp` / `MakeWindow.wbp` を作り直す（[§7.1](#71-ab4-互換の-radusewindow1)）。`.wnd` が無ければ何もしない |

終了コードは、成功で 0、引数の誤りで 1（使い方を出す）、作れないとき（名前・既にある・書けない・`.wnd` が読めない）で 2 です。リリースでは `ProjectEditor` の隣に置きます（`release_build.ps1` / `release_build.sh` が作ります）。Linux 版は CP932 の変換表を持たないので、Shift_JIS ではなく UTF-8 で書きます。

## 8. メッセージからソースへ

コンパイルを始めると、別ウィンドウ「Message」が開きます。閉じる操作は隠すだけで、次のコンパイルで再表示します。

`error: ` または `warning: ` で始まる行を、押した位置から 3 ピクセル以内で離すと移動します。ドラッグでは移動しません。

| 行の形 | 移動先 |
|---|---|
| `error: file(行):` / `warning: file(行):` | そのファイルの行頭。未オープンなら開く |
| `error: line 行:` / `warning: line 行:` | 前面ソースのその行。ファイル名は無い |

`file` が相対パスのとき、プロジェクトがあれば `.pj` のディレクトリ、無ければ前面ソースのディレクトリを前置します。行番号は 1 始まりです。位置の取れない行は無視します。

## 9. ヘルプ

ヘルプメニューの「actba64 ヘルプ」と、キーワード指定なしの表示は、次の順で見つけた `actba64_ref.html` をブラウザで開きます。

1. exe と同じディレクトリの `help\actba64_ref.html`
2. その一つ上の `help\actba64_ref.html`
3. カレントディレクトリの `help\actba64_ref.html`

「キーワード」と F1 は、キャレット位置の識別子（英数字と `_`。先頭の `#` は除く）を小文字にして、既知の語なら HTML のアンカーを付けます。未知の語はアンカーなしで同じ HTML を開きます。ファイルが無いときはメッセージボックスを出します。

## 10. 表示言語

UI 文字列の既定は英語（組み込み）です。exe と同じディレクトリの `setting.ini` に `Language=<code>` があると、`ProjectEditor_lang_<code>.csv` で上書きします。省略、空、`en` は英語のままです。`ja` は同梱の `ProjectEditor_lang_ja.csv` を読みます。

CSV は UTF-8 の `id,text` です。空行と、`#` `;` `[` で始まる行は読み飛ばします。id は [UiStrings.sbp](../src/projecteditor/UiStrings.sbp) の `UI_*` と一致します。パックに無い id は英語のままです。

設定ダイアログは English / Japanese の 2 択です。言語を変えて OK すると `setting.ini` を書き直し、「再起動して設定を読み直しますか？」と尋ねます。はいなら新しいプロセスを起動して現在のウィンドウを閉じます。再起動時に、開いていたファイルは渡しません。コンパイル結果の英文（`Compile succeeded.` など）はパックの対象外です。

## 11. 描画

等幅フォントは OS の `MS Gothic` です（無い環境では Windows が固定ピッチの別のフォントを選びます）。Linux 版は OS の等幅フォント（IPA ゴシック、Takao ゴシック、DejaVu Sans Mono、Liberation Mono などのうち最初に開けたもの）です。文字高さは 16、行の高さは 18、上の余白は 10 です。左にはソースの行番号（1 始まり）を出し、その右に本文を置きます。行数に合わせて欄の幅が広がります。キャレットのある行の番号は濃い色です。折り返しと横スクロールはありません。

タブは 4 桁ごとです。キャレット、選択、強調は、描いた幅と同じ桁を使います。文字は TextShaping なしで描きます。

| 対象 | 色 |
|---|---|
| キーワード、対応する `#` 指令 | 青 `RGB(0, 0, 200)` |
| `'` から行末、および `/*` … `*/`（行をまたぐ）。N88BASIC構文(-pN88) のときは `REM` から行末も | 緑 `RGB(0, 128, 0)` |
| `"` で囲んだ文字列 | 赤 `RGB(163, 21, 21)` |
| それ以外（数値を含む） | 黒 |

キーワードとして色を付ける語は、exe と同じディレクトリの `keywords.txt` です。1 行に 1 語で、大小は区別しません。空行と、`'` または `;` で始まる行は読み飛ばします。ファイルが無いときはキーワード色を付けません。`$` で終わる名前も 1 語として見ます。

`#` 指令として青くするのは `#n88basic` `#prompt` `#console` `#strict` `#include` `#usewindow` です。

縦スクロールは行単位です。キャレットが画面外なら、見える位置まで寄せます。

## 12. フォームデザイナ

**ファイル → 新しいフォーム** は、[Forms.sbp](../src/Include/Forms.sbp) の `Form` を継承したフォームのファイルを書き、開いてすぐデザイン画面にします。フォームは `Class FormN`（400 x 300、見出しは名前、`WndProc` と `InitializeComponent`）だけで、`#include` は書きません。N88BASIC構文(-pN88) と ActiveBasic2構文(-pAB2) では `Forms.sbp` を使えないので、項目は灰色で選べません。

- プロジェクトを開いていないとき: まず一時フォルダー `%TEMP%\ActBa64Temp\NewN\`（N は 1 から、無い番号）に次の 3 つを `xxx` = `project1` で書いてプロジェクトを開き、`Form1.abp` をデザイン画面で開きます。保存先はまだ尋ねません。実行・コンパイルはこの一時フォルダーで訳します（`%TEMP%` に書けないときだけ、すぐ保存先を尋ねます）
  - `xxx.pj`: `#NAME=xxx`、`#PLATFORM` は今の 64bit / 32bit、`#USEWINDOW=1`、`#OUTPUT_RELEASE=.\xxx.exe`、`#SOURCE` に `xxx.abp` と `Form1.abp`
  - `xxx.abp`（メイン）: `#include <Forms.sbp>` と、`Dim mainForm As Form1` / `Application.Initialize()` / `Application.Run(mainForm)`
  - `Form1.abp`: `Form1` のクラス
- 一時フォルダーのプロジェクトのメンバーを上書き保存・名前を付けて保存したとき（Ctrl+S、閉じるときの「はい」も）と、終了・再起動するときの「はい」で、保存先の `.pj` を尋ねます（既定の名前は `project1.pj`）。選んだフォルダーへ、開いている文書の今の内容を含めてメンバーを写し（メインの `project1.abp` は `xxx.abp` に、`.pj` の `#NAME` / `#OUTPUT_RELEASE` / `#OUTPUT_DEBUG` も `xxx` に）、移した先のプロジェクトを開き直します。開いている文書も移した先のパスになり、一時フォルダーのファイルは消します。移し先に同じ名前のファイルがもうあれば、何も書かずにやめます。終了で「いいえ」なら、一時フォルダーに残したまま、そのメンバーの保存確認も出さずに閉じます
- プロジェクトを開いているとき: `.pj` のフォルダーにも `#SOURCE` にも無い `FormN.abp`（N は 1 から）を書き、`.pj` の `#SOURCE` の最後に足して（`.pj` の文字コードと改行はそのまま）、デザイン画面で開きます。メインからそのフォームを出す行は書きません

新しく書くファイルは UTF-8（BOM なし）、改行は CRLF です。

RAD の第一段階です。前面のソースに `Sub InitializeComponent`（`Override Sub InitializeComponent()` など）があり、その `End Sub` で閉じていれば、**F12** でデザイン画面に切り替わります。もう一度 F12 でソースに戻ります。`InitializeComponent` の無い文書では音が鳴るだけです。

ソース子ウィンドウの上には、いつも **コード**、**デザイナー**、**AB4デザイナー** のタブ（`Language=ja` のとき。英語は Code / Designer / AB4 Designer）が並びます。今の画面のタブは白く、押すとその画面に切り替わります。`InitializeComponent` の無い文書ではデザイナーの文字が、`.wnd` でない文書では AB4デザイナーの文字が灰色で、押しても音が鳴るだけです（今の画面のまま）。ソースの 1 行目とデザイン画面は、タブの帯（高さ 26）の下から描きます。デザイン中はタイトルに ` [Design]` が付きます。デザイン中かどうかは子ウィンドウごとに覚えます。

デザイン画面は、`InitializeComponent` の中の `Width` / `Height` の大きさの窓を左上（104, 42。タブの帯の下、左のツールボックスの右）に描きます。見出しは `Caption = "..."` の文字です。`Width` / `Height` が無いか数でなければ 400 x 300 で描きます。左下に今の大きさを出します。

窓の右辺・下辺・右下（白い四角）を引くと大きさが変わり、離したときに `InitializeComponent` の `Width = 数` / `Height = 数` の数だけを書き換えます。変わった方だけを書き、行の残り（コメントなど）はそのままです。行が無ければ `End Sub` の直前に足します。最小は 80 x 40 です。書き換えは 1 回の編集で、元に戻す（Ctrl+Z / メニュー）で戻せます。

名前は大文字小文字を区別しません。`'` で始まる行と、`InitializeComponent` の外の行は見ません。窓の位置（`Left` / `Top`）はまだ変えられません。

`InitializeComponent` の中の `AddControl(名前)` の行を部品とみなし、窓の中（見出しの帯の下を 0, 0 とする座標）に `名前.Left` / `名前.Top` / `名前.Width` / `名前.Height` の四角で描きます。描き方はクラスのフィールドの `名前 As 型` の型で変わります（[Forms.sbp](../src/Include/Forms.sbp) の部品）。

| 型 | 描き方 |
|---|---|
| `Button` | `名前.Caption` の文字の押しボタン |
| `PictureBox` | 白地にへこんだ枠と、灰色の名前 |
| `Panel` | 出っ張った板と、真ん中に `名前.Caption` |
| `Label` | `名前.Caption` を左寄せの 1 行 |
| `CheckBox` | 左に印の四角、その右に `名前.Caption` を左寄せの 1 行 |
| `RadioButton` | 左に印の丸、その右に `名前.Caption` を左寄せの 1 行 |
| `EditBox` | 白地にへこんだ枠と、`名前.Caption` を左寄せの 1 行 |
| `GroupBox` | 彫った線の枠と、左上に `名前.Caption`（中は塗らない） |
| それ以外・宣言が無い | `Button` と同じ |

書かれていない値は 0, 0, 75 x 25 です。`Panel1.AddControl(...)` のような、ほかの部品に載せる行は見ません。

部品を押すと選ばれ、右辺・下辺・右下に白い四角が出ます。左下には選んだ部品の名前・位置・大きさが出ます。部品を引くと動き（左上は 0 より前に出ません）、選んだ部品の白い四角を引くと大きさが変わります（最小 8 x 8）。重なっていれば、後に `AddControl` した方を掴みます。離したときに、変わった値の `名前.Left = 数` などの数だけを書き換えます。行が無ければ `End Sub` の直前に足します。部品の外を押すと選びが外れます。部品の削除はまだありません。

**ツールボックス** はデザイン画面の左の帯で、見出し「Toolbox」と組「General」の下に **Pointer** / **Button** / **Image** / **Panel** / **CheckBox** / **RadioButton** / **EditBox** / **Label** / **GroupBox** をアイコン付きで 1 行ずつ並べます。選んでいる行は水色の帯と青い枠で、ツールを選んでいないときは Pointer です。ツールを押すと選ばれ（もう一度押すか、Pointer を押すか、Esc でやめる）、窓のクライアント領域の上ではカーソルが十字になります。そこを押すと、押した位置を左上にして部品を 1 つ足し、選びます。足したらツールの選びは外れます。クライアント領域の外を押すとツールの選びだけ外れます。

| ツール | 名前 | 型 | 大きさ | `Caption` |
|---|---|---|---|---|
| Button | `Button1`、`Button2` … | `Button` | 75 x 25 | 名前 |
| Image | `Image1` … | `PictureBox` | 100 x 100 | 書かない |
| Panel | `Panel1` … | `Panel` | 200 x 100 | 名前 |
| CheckBox | `CheckBox1` … | `CheckBox` | 100 x 20 | 名前 |
| RadioButton | `RadioButton1` … | `RadioButton` | 100 x 20 | 名前 |
| EditBox | `EditBox1` … | `EditBox` | 120 x 24 | 名前 |
| Label | `Label1` … | `Label` | 100 x 20 | 名前 |
| GroupBox | `GroupBox1` … | `GroupBox` | 200 x 100 | 名前 |

番号は、載せた部品にもフィールドの宣言にも無い一番小さい数です。書き足すのは次の 2 か所で、1 回の編集として元に戻せます。

- フィールド: `名前 As 型` の行を、`InitializeComponent` のあるクラスの中で最後の部品の宣言（`Button` / `Label` / `PictureBox` / `Panel` / `CheckBox` / `RadioButton` / `EditBox` / `GroupBox` / `OpenFileDialog`）の次に足します。無ければ、最初のメソッド（`Sub` / `Function`）より前の `Private` の行の次（字下げは `Private` + 4）、それも無ければ `Inherits` の行（無ければ `Class` の行）の次に `Private` の行ごと足します。フィールドはメソッドより後ろに置くとコンパイルできないので、新しいフォームの雛形（`Public` の `WndProc` の後ろに `Private`）でも `Inherits` の次に `Private` を足します。字下げは前の行に合わせます
- `InitializeComponent`: 空行と、`名前.Left` / `.Top` / `.Width` / `.Height`（Image 以外は `.Caption = "名前"`）と `AddControl(名前)` の行を、最後の `AddControl` の行の次に足します。`AddControl` が無ければ `End Sub` の直前（字下げは `End Sub` + 4）です

パネルやグループボックスの上に置いても、部品はフォームに載せます（`Panel1.AddControl` はまだありません）。重なった所を押すと後に `AddControl` した方を掴むので、枠の中の部品は枠より後に置いてください。

型が `Button` の部品を **ダブルクリック** すると、押したときの処理を書けるようにしてコードの画面に切り替え、`Sub 名前Click()` の中の空の行にキャレットを置きます。無いものだけを書き足すので、2 回目からは書かずにその `Sub` へ飛びます。

- `Sub 名前Click()` / 空の行 / `End Sub`: `InitializeComponent` の行の直前（そのすぐ上のコメント行があれば、その前）。字下げは `InitializeComponent` の行と同じ
- `WndProc` で呼ぶ行（`名前.Handle` を含む行がもうあれば書かない）
  - `BN_CLICKED` の行が `Then` で終わるブロックなら、その中の先頭に `If lParam = 名前.Handle Then 名前Click()`
  - `BN_CLICKED` の行が 1 行の `If` なら、その次に `If HIWORD(wParam) = BN_CLICKED And lParam = 名前.Handle Then 名前Click()`
  - `BN_CLICKED` が無ければ、`WndProc = Super.WndProc(...)` の行（無ければ `End Function`）の前に `If msg = WM_COMMAND Then` / `If HIWORD(wParam) = BN_CLICKED Then` のブロック
  - `WndProc` が無ければ、`Sub 名前Click()` の前に `Public`、`Override Function WndProc(...)`、`Private` を足す

書き足しは 1 回の編集で元に戻せます。`Button` 以外の部品のダブルクリックは、ふつうに押したのと同じです。

デザイン中に効くキーは F12、Esc（ツールの選びを外す）、Ctrl+S、Ctrl+Z / Ctrl+Y です。文字入力、ホイール、右クリックメニューは効きません。

### AB4デザイナー

AB 4.20 のウィンドウ定義ファイル（`.wnd`、[§7.1](#71-ab4-互換の-radusewindow1)）は、開くと（ファイル → 開く、プロジェクトのツリー、ドロップ、起動引数のどれでも）初めから AB4デザイナーのタブで出ます（Windows 版。Linux 版はコードのまま）。コードのタブか **F12** で文字に戻り、AB4デザイナーのタブか F12 でまた絵に戻ります。AB4デザイナーでは `.wnd` の窓を絵で見て、部品の位置と大きさ、窓の大きさを変えられます。プロジェクトのツリーで `<名前>.abp` の下の `.wnd` を選ぶと、その文書が開きます。

- `WINDOW:` ごとに、`SIZE` の大きさ（枠を含む。無いか 0 なら 400 x 300）の窓を左上（16, 42）から下へ 16 ずつ空けて並べ、見出しに `CAPTION` の文字を出します。`POINT` は見ません。
- 窓の中に `ITEM` の部品を、見出しの帯の下を原点にして描きます。描き方は種類（`ITEM` の 9 番目の数）で決まります: 1 押しボタン、2 チェックボックス、3 白い欄と右の ▼（ComboBox。欄の高さは 21 で、`ITEM` の高さはリストを開いた高さ）、4 白い欄と文字（EditBox）、5 囲みの枠、6 横のスクロール バー、7 様式の枠（ImageBox。`SS_BLACKFRAME` は黒など）、8 / 9 / 12 白地と名前（ListBox / ListView / TreeView。`WS_EX_CLIENTEDGE` ならへこんだ枠）、10 ラジオボタン、11 文字だけ（Static）、13 縦のスクロール バー、14 ▲ ▼ の 2 つのボタン（UpDown。`UDS_HORZ` なら ◀ ▶）、15 へこんだ枠（ProgressBar）、16 溝とつまみ（TrackBar。`TBS_VERT` なら縦）。
- 窓が欄に入りきらないときは、ホイールで上下に、Shift + ホイールで左右にずらします。
- 部品を押すと選びます（右辺・下辺・右下につまみ）。そのまま引くと動き、選んだ部品の右辺・下辺・右下を引くと大きさが変わります（8 より小さくはならない）。部品の無い所を押すと選びを外します。
- 窓の右辺・下辺・右下を引くと窓の大きさが変わります（80 x 40 より小さくはならない）。
- 離したときに、部品なら `ITEM` の x, y, 幅, 高さ を、窓なら `SIZE` を書き換えます（`SIZE` の行が無ければ `WINDOW:` の次の行に足す）。ほかの欄と行はそのままで、文字コード（AB 4.20 の `.wnd` は Shift_JIS）と改行も変えません。書き換えは 1 回の編集として元に戻せます。保存は Ctrl+S です。
- 左下に、選んでいる部品の名前と位置・大きさ（選んでいなければ窓と部品の数）を出します。
- 右の欄の上は「- コントロール -」の道具箱です。AB 4.20 と同じく小さな絵のボタンで、左に 3 列・右に 2 列並べます（段 0: ポインタ / 1: テキスト・エディット・グループ | リストビュー・リスト / 2: ボタン・チェック・ラジオ | コンボ・ツリービュー / 3: 横スクロール・縦スクロール・アップダウン | イメージ / 4: トラックバー・プログレス）。絵は線と塗りで描きます（ビットマップは使わない。Linux 版も同じ）。選んでいる道具はへこんで見えます。道具の上にマウスを置くと下の帯にその名前を、道具を選んでいる間はその名前と使い方を出します。道具を選んで窓の中を押すと、その種類の部品を既定の大きさで足します。引けば引いた四角で足します。名前は種類の頭（`CommandButton`、`Static` など）に、その窓で空いている一番小さい番号を付けたもので、文字（`Button2` など）と様式・拡張様式は AB 4.20 が新しい部品に付けるものと同じです。`ITEM` の行は窓の `END` の前に足します。足したら道具はポインタに戻り、足した部品を選びます。
- **Del** で選んだ部品の `ITEM` の行を消します。**Esc** で道具と選びをやめます。
- 部品は窓のクライアントの外にはみ出した分を描きません。
- 右の欄の下は、選んでいる部品のプロパティです（「- 種類 プロパティ -」）。
  - **ID** の「変更」で名前を変えます（英字か `_` で始まり英数字と `_` だけ。同じ窓にもうある名前と、使えない名前は音が鳴るだけ）。
  - **キャプション** の「変更」で文字を変えます（押しボタン・チェック・エディット・グループ・ラジオ・テキスト）。文字の中の `"` は `'` にします。日本語も入れられます（ファイルの文字コードで書く）。
  - **スタイル**: どの種類にも 無効（使用不可）・可視・グループ・タブ ストップ があり、そのあとに種類ごとの様式が並びます（テキストの配置・プリフィックスなし・通知、エディットの複数行・番号・スクロール バー・パスワード・読み取り専用など、ボタンの種類・アイコン・ビットマップ・複数行・水平/垂直方向の配置、チェックの種類（自動チェック・3 ステート など）・プッシュ ボタン型・左揃えテキスト、リストの選択・オーナー描画・文字列あり・複数列・ソート、コンボのタイプ、スクロール バーの配置、アップダウンの方向・アタッチ・自動関連付け・数値の自動表示・桁区切りなし・ワードラップ・方向キー、トラック バーの方向・ポイント・マークなし・マーク自動設定・選択可能、プログレス バーの垂直方向・スムーズ、イメージのタイプ・通知・中央配置・右に揃える、リストビューの表示、ツリービューのボタン・線）。チェックの行を押すとそのビットを入れ替え、「見出し: 値 ▼」の行を押すと次の値にします。
  - **拡張スタイル** のボタンで、様式の行の代わりに拡張様式の行（くぼんだ枠・段差の枠・ダイアログの枠・透明・ファイルのドロップを受ける・親に知らせない）を出します。もう一度押すと様式に戻ります。
  - どれも `ITEM` の名前・文字・様式・拡張様式の欄だけを書き換えます（1 回の編集）。行が欄に入りきらないときは、欄の上のホイールでずらします。
  - 文字を入れる小さな窓は、Windows 版はダイアログ（Enter で OK、Esc でやめる）、Linux 版は 1 行の入力欄です。
- 部品を選んでいないときは、窓のプロパティ（「- ウィンドウ プロパティ -」）です。対象は最後に押した窓（初めは最初の窓）です。
  - **識別名**（`WINDOW:` の名前）・**ハンドル**（`HANDLE`）・**キャプション**（`CAPTION`）・**フォント**（`FONT`。「名前, 大きさ」で入れ、高さと名前の欄だけを変える）・**アイコン**（`ICONID`。空にすると行を消して標準のアイコン）を「変更」で書き換えます。識別名とハンドルは名前に使えるものだけ、識別名はほかの窓と同じにできません。
  - **背景**（`BGCOLOR`）は見るだけです（`ProjectCmd -regen` は背景にいつも 3D FACE を使う）。
  - **メニュー** の行を押すと、なし →ファイルの `MENU:` の順に `MENUID` を替えます（なしでは行を消す）。**タイプ** の行を押すと 通常ウィンドウ → モーダル ダイアログ → モードレス ダイアログ と `TYPE` を替えます。
  - **スタイル**: ウィンドウの種類（オーバーラップ / ポップアップ / 子）、タイトル バー、サイズ変更枠、システム メニュー、最小化ボタン、最大化ボタン、最小化、最大化、水平・垂直スクロールバー、無効、兄弟ウィンドウをクリップ、子ウィンドウをクリップ、可視。**拡張スタイル** のボタンで 最前面・ツール ウィンドウ・くぼんだ枠・浮き出た枠・ダイアログの枠・ファイルのドロップを受ける・タスク バーに出す・Tab で子に移る に切り替えます。`STYLE` / `EXSTYLE` を書き換えます（`&H80000000` 以上の値も正しく扱う）。

## 13. このエディタがしないこと

置換、折り返し、符号の手選び、プロジェクトの新規作成ウィザード、デバッガは持っていません。フォームデザイナは、窓の大きさと部品の位置と大きさを変え、ツールボックスから部品を足すだけです。部品の削除、名前や `Caption` の書き換え、Button 以外のイベントの行の生成はできません。Ctrl+N や Ctrl+O もありません。`src/projecteditor` の `Callback.wbp` / `MakeWindow.wbp` は、このエディタ自身を組むためのファイルです（`ProjectEditor.pj` は `#USEWINDOW=3` なので、[§7.1](#71-ab4-互換の-radusewindow1) の生成はしません）。

## 14. Linux 版

`actba64 ProjectEditor.pj -linux -o ProjectEditor` で、x86-64 Linux で動くエディタになります（`libX11.so.6` と `libfreetype.so.6` を使う動的リンクの ELF）。隣に置くものは Windows 版と同じで、Linux 版の `actba64`（拡張子なし）、`Include`、`keywords.txt`、`help`、言語パックです。X の窓が開けなければ（`DISPLAY` が無いなど）メッセージを出して終了します。

窓は 1 枚です。上からメニューの帯、文書のタブ、文書、メッセージ欄（訳したときに開き、見出しの × で閉じる）を並べます。MDI の子窓の代わりに文書ごとのタブがあり、タブの × か中ボタンで閉じます（保存の確認は Windows 版と同じ）。`.pj` を開くと左にプロジェクトの欄が出て、行を押すとそのファイルを開きます。欄の見出しの × でプロジェクトを閉じます。文書が無いときは Ctrl+N で新規、Ctrl+O で開きます。

描くところ（[UiDraw.sbp](../src/projecteditor/UiDraw.sbp) の `Ui_` 関数）は Windows 版と同じコードで、Linux 版は [UiX11.sbp](../src/projecteditor/UiX11.sbp) が画素バッファと FreeType で描きます。キー・マウス・メニューの処理も Windows 版と同じで、X のイベントを `WM_*` にして渡します（[LxFrame.sbp](../src/projecteditor/LxFrame.sbp)）。メニュー、右クリックのメニュー、メッセージボックス、ファイルの選択、検索の入力、設定の言語の選択は自前で描きます（[LxMenu.sbp](../src/projecteditor/LxMenu.sbp)、[LxDialog.sbp](../src/projecteditor/LxDialog.sbp)）。

- **ファイルの選択**: 入力欄にファイル名かパス（相対なら一覧のフォルダーから）を書いて Enter。一覧のダブルクリックでフォルダーに入る・ファイルを選ぶ。`.` で始まる名前は出しません。保存で拡張子が無ければ `.abp` を付け、あれば上書きを尋ねます
- **クリップボード**: X の `CLIPBOARD`（UTF-8）。ほかのアプリとやり取りできます
- **訳し先**: Basic メニューに **Linux (ELF)** が増え、Linux 版の既定です（`-linux`、出力に `.exe` を付けない）。64bit / 32bit も選べますが、Windows の exe はここでは実行できないので訳すだけです
- **実行**: コンソールのプログラムは端末（`$TERMINAL`、無ければ `x-terminal-emulator` / `gnome-terminal` / `konsole` / `xfce4-terminal` / `xterm`）の窓で動かし、終わると Enter を待ちます。端末が無ければ、exe のフォルダーで動かして出力と終了コードをメッセージ欄に出します（標準入力は `/dev/null`）
- **ヘルプ**: `xdg-open` で開きます

Linux 版にまだ無いもの: 日本語入力（IME / XIM）、ファイルのドロップ、フォームデザイナ（デザイナーのタブと F12 は音が鳴るだけ）、入力欄の途中の編集。
