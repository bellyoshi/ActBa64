# Distribution terms for programs you create / 自作プログラムの配布条件

ActBa64 itself is licensed under the [MIT License](../LICENSE). In addition, the following terms apply to programs you build with ActBa64. If the English and Japanese texts differ, the English text prevails.

ActBa64 本体は [MIT ライセンス](../LICENSE)（[日本語訳](license.ja.md)）です。これに加えて、ActBa64 で作ったプログラムには以下の条件が適用されます。英語と日本語の内容に違いがある場合は英語が優先されます。

## English

The copyright in executable files (EXE files, DLL files) produced by the ActBa64 compiler, and in any development files the user creates, belongs to the user who created the program.

Programs created by the user (source code, executable files and other program resources) may be distributed by the user. There are no restrictions on commercial use. You do not need to contact bellyoshi when distributing them.

As an additional permission, the portions of ActBa64's libraries (such as the files under Include) that are compiled into or linked into an executable file produced by the ActBa64 compiler may be distributed as part of that executable file without including the copyright notice and permission notice of the MIT License.

## 日本語

ActBa64 コンパイラによって抽出された実行ファイル（EXE ファイル、DLL ファイル）、及びユーザーが任意に作成した開発に関わるファイルの著作権は、そのプログラムを作成したユーザーに発生します。

ユーザーによって作成されたプログラム（ソースコード、実行ファイル、その他のプログラム資源）はユーザーによって配布することが可能です。商用目的での使用制限もありません。配布を行う際に bellyoshi へ連絡する必要はありません。

追加の許可として、ActBa64 コンパイラが出力した実行ファイルに組み込まれた、またはリンクされた ActBa64 のライブラリ（Include 以下のファイルなど）の部分は、MIT ライセンスの著作権表示および許諾表示を含めずに、その実行ファイルの一部として配布できます。
