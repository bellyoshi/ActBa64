# 対応する ActiveBasic のバージョン

## 対応しているバージョン

| バージョン |
|---|
| 3.10 |
| 3.13 |
| 4.23 |
| 4.24 |

これらのバージョンで書かれたプログラムを、ソースを書き換えずにコンパイルして動かすことを目標にしています。

## 5.0

対応していません。

- 5.0 は開発コード・プレビュー版のまま終わったバージョンです。
- ネット上を探しても、5.0 で作られたコードは見つけることができなかったため、動作確認も難しいです。

ただし、5.0 に搭載される予定だった機能は、ゆくゆく ActBa64 に盛り込みます。

## 2.62 以前

変数の宣言が不要など、今のバージョンとは多くの違いがあります。そのままでは動きませんが、`-pN88` を付けると動く可能性があります（[language.md §1.7](./language.md#pn88)）。

```powershell
actba64 old.abp -pN88 -o old.exe
```

ただし、`-pN88` は ActiveBasic よりはるか前の BASIC のプログラムを動かすことを目的としています。
