# 文字コードと API（UTF-8 ⇔ ワイド文字）

ActBa64 の文字列は UTF-8 です（[ActiveBasic との相違 §文字列の内部表現](./different.md#文字列の内部表現)）。Windows の A 版の API は文字列を CP932 として扱うので、そのまま渡すと文字化けします。標準ヘッダ（`Include\default`）の末尾に `A` の付かない API は、ここに挙げるラッパーが UTF-8 とワイド文字（UTF-16）のあいだを変換します。末尾 `A` の Declare は変換しません。

実体は `Include\default` の `BasicUtf8.abp` / `BasicUtf8Msg.abp` / `BasicCmd.abp` / `BasicPath.abp` / `BasicFileW.abp` / `BasicFindW.abp` / `BasicSysW.abp` / `BasicShellW.abp` / `BasicShFolderW.abp` / `BasicRegW.abp` / `BasicOfnW.abp` / `BasicFontW.abp` / `BasicMiscW.abp` / `BasicCaseW.abp` / `BasicMciW.abp` / `BasicPrintW.abp` / `BasicPrintDlgW.abp` / `BasicFindTextW.abp` / `BasicInetW.abp` / `BasicSpiW.abp` / `BasicSbW.abp` と、各 `.sbp` の Declare です。`-linux` では A 版の代わり（`Include\linux`）へ UTF-8 のまま渡します。

## API 別の詳細

- `#n88basic` の窓文字は UTF-8 をワイド文字にして描きます。
- `SetWindowText` / `GetWindowText` / `GetWindowTextLength` / `CreateWindowEx` / `CreateFont` / `SetDlgItemText` / `GetDlgItemText` は UTF-8 をワイド文字 API に渡す。`GetWindowText` は UTF-8 を書き、戻り値は NUL を含まないバイト数。末尾 `A` の Declare は変換しない。
- `InsMenu` / `InsertMenu` / `AppendMenu` / `ModifyMenu` の見出しも UTF-8 をワイド文字 API に渡す。`MF_SEPARATOR` / `MF_BITMAP` / `MF_OWNERDRAW` の第 5 引数は文字列ではないので変換しない。末尾 `A` は変換しない。`GetMenuString` は UTF-8 を書く。
- `InsertMenuItem` / `SetMenuItemInfo` / `GetMenuItemInfo` は、`MIIM_STRING` または文字列の `MIIM_TYPE` のとき `dwTypeData` をワイド文字にする。`GetMenuItemInfo` は UTF-8 を書き、`cch` はそのバイト数。区切り・ビットマップ・オーナードローは変換しない。
- `TextOut` / `GetTextExtentPoint32` / `DrawText` / `DrawTextEx` は UTF-8 をワイド文字数で渡す。長さが負のときは NUL まで。末尾 `A` はバイト数のまま。`DT_MODIFYSTRING` の書き換えは呼び出し側のバッファへ戻さない。
- `CreateStatusWindow` の見出し、`RegisterClassEx` のクラス名とメニュー名、`UnregisterClass` は UTF-8 をワイド文字 API に渡す。65535 以下はアトムなので変換しない。`RegisterClassEx` は呼び出し側の `WNDCLASSEX` を変えない。登録はワイドなので窓は Unicode になり、無印の `DefWindowProc` / `DefFrameProc` / `DefMDIChildProc` は W 版。`GetClassName` は UTF-8 を書く。`GetClassInfoEx` が返すクラス名とメニュー名のポインタは、次に `GetClassInfoEx` を呼ぶまで有効な UTF-8。クラス名がアトム、NULL、または問い合わせに使った変換バッファのときは、引いた名前の UTF-8 を複製して返す。
- ステータスバーへの `SendMessage` の `SB_SETTEXT` / `SB_SETTIPTEXT` は、UTF-8 をワイド文字にして `SB_SETTEXTW` / `SB_SETTIPTEXTW` で送る。`CreateStatusWindow` の窓は Unicode なので、A 版のままだと UTF-8 が CP932 として表示され文字化けするため。窓のクラスが `msctls_statusbar32` のときだけ変換し、ほかのコントロールの `WM_USER+1` などはそのまま。妥当な UTF-8 でなければ A 版のまま。`SB_GETTEXT` は A 版のままなので CP932 を返す。
- `CreateFontIndirect` の `lfFaceName` は UTF-8 をワイド文字 API に渡す。呼び出し側の `LOGFONT` はそのまま。`GetObject` でフォントを読むと、W 版で読んで `lfFaceName` を UTF-8 で書く（32 バイトに入らなければ CP932、それも入らなければ文字の境目で切る）。フォントでない GDI オブジェクトは A 版。`ImmSetCompositionFont` も `lfFaceName` をワイドにして W 版に渡す。
- `ChooseFont` は W 版で開き、選んだフォントの `LOGFONT`（`lfFaceName` は UTF-8）と `lpszStyle`（UTF-8）・`iPointSize`・`rgbColors`・`nFontType`・`Flags` を書き戻す。フック（`CF_ENABLEHOOK`）を使うときは A 版のまま。
- `s[n]` は 0 始まりの 1 バイトです。
- `GetOpenFileName` と `GetSaveFileName` は W 版で開く。呼び出し側の `OPENFILENAME` の写しにワイドのフィルタ（二重 NUL）・初期フォルダ・タイトル・拡張子と、`nMaxFile` / `nMaxFileTitle` 文字のワイドの受け皿（`lpstrFile` に入れた初めのファイル名も写す）を入れて呼び、成功したら `lpstrFile` と `lpstrFileTitle` を UTF-8 で書き、`nFileOffset` / `nFileExtension` を UTF-8 のバイト位置にし、`Flags` と `nFilterIndex` を書き戻す。複数選択（フォルダ 0 ファイル 0 … 0 0）も同じ。CP932 にない文字のファイル名も選べる。UTF-8 が `nMaxFile` に入らなければ CP932 で書き（A 版のパスとして開ける）、それも入らなければ 0 を返す。フック（`OFN_ENABLEHOOK`）・`lpstrCustomFilter` を使うとき、フィルタが妥当な UTF-8 でないとき、`-linux` は、これまでどおり A 版で開き、呼ぶあいだだけ文字列を CP932 にして結果を UTF-8 に直す（CP932 にない文字のファイル名は選べない）。
- `CreateFile` / `GetFileAttributes` / `ShellExecute` / `CopyFile` / `MoveFile` / `DeleteFile` / `CreateDirectory` / `RemoveDirectory` / `SetCurrentDirectory` / `SetFileAttributes` / `LoadLibrary` と、`ChDir` / `MkDir` / `Kill` / `Exec` は、パスが妥当な UTF-8 ならワイド文字 API に渡します。CP932 にない文字（𠮷 など）のパスも扱えます。妥当な UTF-8 でないとき（ファイルから読んだ Shift-JIS など）は A 版に渡すので、CP932 のパスもそのまま開けます。`CopyFile` / `MoveFile` と `ShellExecute` は、文字列のどれか 1 つでも妥当な UTF-8 でなければ、すべて A 版に渡します。末尾 `A` の Declare は変換しません。
- `GetCurrentDirectory` / `GetTempPath` / `GetWindowsDirectory` / `GetSystemDirectory` / `GetFullPathName` は、ワイド文字 API の結果を UTF-8 で書きます。戻り値は A 版と同じ決まりで、文字数の代わりにバイト数です（入れば NUL を除いた書いたバイト数、入らなければ NUL を含めた要るバイト数で、何も書きません）。`GetFullPathName` の `lpFilePart` は、書いた UTF-8 の中の名前の先頭を指します。
- `FindFirstFile` / `FindNextFile` はワイド文字 API で探し、`WIN32_FIND_DATA` の `cFileName` / `cAlternateFileName` を UTF-8 で書きます。探すパスが妥当な UTF-8 でなければ CP932 とみます。UTF-8 の名前が 260 バイトに入らないときは CP932 で書き（A 版のパスとして開けます）、それも入らなければ文字の境目で切った UTF-8 を書きます。
- `GetCommandLine`（と、それを使う `common\CmdLine.abp` の `GetCmd`）は UTF-8 を返します。初めて呼んだときに `GetCommandLineW` を UTF-8 にしたものを持っておき、同じポインタを返します。
- `CreateProcess` は、コマンドラインが妥当な UTF-8 ならワイド文字 API に渡します。`GetCommandLine` が UTF-8 なので、受け取った引数をそのまま子プロセスに渡せます。アプリ名やカレントフォルダを渡すとき、`STARTUPINFO` の `lpDesktop` / `lpTitle` を使うときは A 版のままです。
- `GetEnvironmentVariable` / `SetEnvironmentVariable` は UTF-8 の名前と値をワイド文字 API に渡し、読んだ値を UTF-8 で書きます（戻り値の決まりは `GetCurrentDirectory` と同じ）。`GetComputerName` / `GetUserName` も UTF-8 で書き、`nSize` はバイト数です。
- `DragQueryFile` はファイル名を UTF-8 で書きます。`lpszFile` が 0 なら NUL を除いた要るバイト数を、`iFile` が `&HFFFFFFFF` ならファイルの数を返します。入らなければ文字の境目で切ります。
- `FormatMessage` は、差し込み（`Arguments`）を使わないとき（`Arguments` が 0 か `FORMAT_MESSAGE_IGNORE_INSERTS`）はワイド文字 API で作り、UTF-8 で返します。日本語の Windows のエラー文も、そのまま `Print` できます。戻り値はバイト数で、`FORMAT_MESSAGE_ALLOCATE_BUFFER` なら `LocalAlloc` した UTF-8 を返します（`LocalFree` で解放）。差し込みがあるときは、`%1` などの型が分からないので A 版のまま（CP932）です。
- `OutputDebugString` は UTF-8 をワイド文字 API に渡します。
- 無印の `GetMessage` / `PeekMessage` / `DispatchMessage` / `PostMessage` / `PostThreadMessage` / `CallWindowProc` / `SetWindowLong` / `SetWindowLongPtr` / `GetWindowLong` / `GetClassLong` / `SetClassLong` は W 版です。`RegisterClassEx` で登録した窓は Unicode なので、メッセージの取り出しもそれに合わせ、`WM_CHAR` には UTF-16 の値（CP932 にない文字はサロゲートの組）がそのまま届きます。`GWL_WNDPROC` で付けた手続き（サブクラス）も Unicode のメッセージを受け、`WM_SETTEXT` などの `lParam` はワイド文字列です。前の手続きへは無印の `CallWindowProc` で渡します（末尾 `A` の `CallWindowProcA` で渡すと、ワイド文字列が CP932 とみなされて化けます）。`GetClassLong(h, GCL_MENUNAME)` が返すのはワイド文字列です。
- `MessageBox`（`MsgBox` も）は本文と題をワイド文字 API に渡します。CP932 にない文字も出せます（`-linux` は従来どおり）。
- `FindWindow` / `ShellAbout` はクラス名・題・文字列をワイド文字 API に渡します。`PlaySound` も音の名前やパスをワイド文字 API に渡します（`SND_MEMORY` のときはデータなのでそのまま）。
- `GetDriveType` / `GetDiskFreeSpace` / `GetDiskFreeSpaceEx` / `ExtractIcon` / `ExtractIconEx` / `LoadCursorFromFile` は、パスが妥当な UTF-8 ならワイド文字 API に渡します（違えば A 版）。
- `SHBrowseForFolder` は、呼ぶあいだだけ `lpszTitle` をワイドにして W 版を呼び、選んだフォルダーの表示名を `pszDisplayName` に UTF-8 で書き戻します。`SHGetPathFromIDList` はパスを UTF-8 で書きます。どちらも受け皿は MAX_PATH（260 バイト）とみて、UTF-8 が入らなければ CP932 で書きます（それも入らなければ文字の境目で切ります）。戻り値の pidl は `VoidPtr` です。コールバック（`lpfn`）は W 版のダイアログから呼ばれるので、`BFFM_VALIDATEFAILED` は W 版の番号（4）で来ます。
- `SHFileOperation` は `pFrom` / `pTo`（二重 NUL の並び）と `lpszProgressTitle` をワイドにした写しで W 版を呼び、`fAnyOperationsAborted` / `hNameMappings` を書き戻します。`pFrom` / `pTo` が妥当な UTF-8 でなければ A 版です。
- レジストリの `RegOpenKeyEx` / `RegCreateKeyEx` / `RegDeleteKey` / `RegDeleteValue` / `RegSetValueEx` / `RegQueryValueEx` は、キーと値の名前をワイド文字 API に渡します。`REG_SZ` / `REG_EXPAND_SZ` / `REG_MULTI_SZ` の値は、書くときに UTF-8（妥当でなければ CP932 とみる）をワイドにし、読むときに UTF-8 にします。`RegQueryValueEx` の `lpcbData` は UTF-8 のバイト数（末尾の NUL を含む。`REG_MULTI_SZ` は NUL 2 つ）で、受け皿に入らなければ要るバイト数を入れて `ERROR_MORE_DATA`（234）を返します。ほかの型の値はそのままです。
- `lstrcmpi` / `CompareString` は、ASCII だけの文字列なら A 版（同じ結果で速い）、ほかは UTF-8（妥当でなければ CP932）をワイドにして W 版で比べる（全角の英字や `Ä` も大文字・小文字を区別せずに比べられる）。`CharUpper` / `CharLower` も同じで、その場で書き換える（UTF-8 にしたとき元より長くなるなら書き換えない）。1 文字（ポインタが 65536 未満）の形は A 版のまま。
- `RegisterWindowMessage` / `RegisterClipboardFormat` / `SetComputerName` / `CreateMailslot` は名前をワイド文字 API に渡す。`GetClipboardFormatName` / `mciGetErrorString` は UTF-8 で書く（入らなければ文字の境目で切る）。`GetFileTitle` は題を UTF-8 で書き、受け皿が小さければ NUL を含めた要るバイト数を返す。`GetCompressedFileSize` はパスをワイド文字 API に渡す。`ExtractAssociatedIcon` はパス（MAX_PATH の受け皿）をワイドにして呼び、書き戻すパスも UTF-8。
- `PrintDlg` / `PageSetupDlg` は W 版で開く。プログラムが扱う `hDevMode`（`DEVMODE`）と `hDevNames`（`DEVNAMES`）はこれまでどおり A 版の形（`DEVMODE` は 156 バイト、`DEVNAMES` の位置はバイト）で、プリンター・用紙・ドライバー・ポートの名前だけ UTF-8（`DEVMODE` の 32 バイトの名前に入らなければ CP932）。呼ぶあいだだけワイドの形の写しを作って渡し、成功したら結果を A の形の新しい大域メモリにして返す（入れておいた古いものは解放する）。フック（`PD_ENABLEPRINTHOOK` / `PD_ENABLESETUPHOOK` / `PSD_ENABLEPAGESETUPHOOK` / `PSD_ENABLEPAGEPAINTHOOK`）を使うときは A 版のまま。
- `CreateDC` / `ResetDC` はドライバー・プリンターの名前と `DEVMODE`（A の形、名前は UTF-8）をワイドにして W 版に渡す。日本語の名前のプリンターも開ける。`CreateDC` の `lpszOutput` を渡すときは A 版のまま。
- `mciSendCommand` は W 版に送る。`MCI_OPEN` の型の名前・ファイル名・別名（`MCI_OPEN_TYPE` / `MCI_OPEN_ELEMENT` / `MCI_OPEN_ALIAS`。`*_ID` のときは番号なのでそのまま）、`MCI_LOAD` / `MCI_SAVE` のファイル名は、呼ぶあいだだけ構造体のポインタをワイドの文字列に入れ替えて戻す。`MCI_INFO` / `MCI_SYSINFO` の答えは UTF-8 で書く（`dwRetSize` バイトに入らなければ文字の境目で切る）。ほかの命令はそのまま。
- `FindText` は W 版で開く。ダイアログはモードレスなので、開いているあいだだけ使う W の形の写し（後ろにワイドのバッファ）を作って渡し、持ち主の窓（`hwndOwner`）をサブクラス化する。`FINDMSGSTRING` が届くと `Flags` と検索語（`lpstrFindWhat`）・置換語を呼び出し側の `FINDREPLACE` へ UTF-8 で書き戻し（`wFindWhatLen` バイトに入らなければ文字の境目で切る）、`lParam` を呼び出し側の構造体にして元の窓手続きへ渡す。`FR_DIALOGTERM` か持ち主の窓の `WM_NCDESTROY` で写しを捨て、ほかにつないでいなければ窓手続きを戻す。フック（`FR_ENABLEHOOK`）を使うときと、同時に 9 つ目を開くときは A 版のまま。
- WinINet の `InternetOpen` / `InternetConnect` / `FtpGetFile` / `FtpSetCurrentDirectory` / `FtpGetCurrentDirectory` / `FtpFindFirstFile` / `InternetFindNextFile` は W 版。渡す文字列は UTF-8（CP932 のバイト列も読む）。`FtpGetCurrentDirectory` の答えは UTF-8 で、`lpdwCurrentDirectory`（`*DWord`）は渡すときはバイトの大きさ、返るときは書いたバイト数（入らなければ FALSE で要るバイト数）。見つけたファイルの `WIN32_FIND_DATA` は `FindFirstFile` と同じく名前を UTF-8 で書く。
- `SystemParametersInfo` の `LOGFONT` を含む命令（`SPI_GETICONTITLELOGFONT` / `SPI_SETICONTITLELOGFONT`、`SPI_GETNONCLIENTMETRICS` / `SPI_SETNONCLIENTMETRICS`、`SPI_GETICONMETRICS` / `SPI_SETICONMETRICS`）は W 版に送る。構造体はこれまでどおり A の形（`LOGFONT` は 60 バイト、`cbSize` も A の形の 344 / 340 / 76）で、`lfFaceName` だけ UTF-8（32 バイトに入らなければ CP932）。呼ぶあいだだけワイドの形の写しを作る。壁紙（`SPI_SETDESKWALLPAPER` / `SPI_GETDESKWALLPAPER`）のパスも UTF-8（`SETWALLPAPER_DEFAULT` は A 版のまま）。ほかの命令は A 版のまま。
- ステータスバーの `SB_GETTEXT` / `SB_GETTEXTLENGTH` / `SB_GETTIPTEXT` は W 版で読んで UTF-8 で返す。長さ（下の 16 ビット）は UTF-8 のバイト数なので、`SB_GETTEXTLENGTH` + 1 バイトの受け皿で `SB_GETTEXT` が読める。種類（上の 16 ビット）はそのまま。持ち主が描く部分（`SBT_OWNERDRAW`）は A 版のまま。
- まだ A 版のまま（CP932）のもの: `IsChar*`（1 バイトを受ける）、`GetVersionEx` / `GetStartupInfo`（`StartDoc` は `-pAB2` の印刷が名前を渡さないので変えていない）。`#N88BASIC` の窓（`RegisterClassExA` の ANSI の窓で、メッセージの取り出しも A 版）。
