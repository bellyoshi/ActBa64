actba64 言語リファレンス

ActiveBasic 互換サブセット → 既定 64bit PE32+。 -actba32 で 32bit PE。完全互換ではありません。

概要

actba64 は ActiveBasic 風ソースを 64bit PE（PE32+） に直接コンパイルします。-actba32 を付けると 32bit PE（PE32） です。Lexer → Parser → AST → IR は共通で、機械語と PE だけ分岐します。エントリは結合後ソースのトップレベル文です。終了は End（コード 0）または ExitProcess(n)。

actba64 <src.abp|.pj> [-actba32] -o <out.exe>
拡張子意味
.abpソース 1 ファイル
.pjプロジェクト（#SOURCE 以下を結合して 1 コンパイル単位）

コメントは ' から行末、または /* ... */（ネスト不可）。識別子は大小文字を区別しません。同一行の : で文を連結できます。行末の _ で継続できます。

型とサイズ

重要: LP64 ではありません。Long は常に 32bit。ポインタ / String / HANDLE は既定 8 バイト、-actba32 では 4 バイトです。

LONGLONG / DWORD64

現状、LongLong / QWord / DWORD64 を 64bit 整数型として演算する機能はありません。Win64 でポインタ幅の値が必要なときは次を使います。

  • ハンドル・ポインタ引数: HANDLE / HWND / *Byte / VoidPtr
  • メッセージ引数: WPARAM / LPARAM / LRESULT（8 バイト）
  • 64bit ビットパターンを保持するだけなら LONG_PTR または UDT（lo/hi の 2×DWord）
TypeDef VoidPtr = *Byte
TypeDef HANDLE = VoidPtr
TypeDef LONG_PTR = VoidPtr
TypeDef ULONG_PTR = VoidPtr
TypeDef LRESULT = LONG_PTR
TypeDef WPARAM = ULONG_PTR
TypeDef LPARAM = LONG_PTR
TypeDef LPSTR = *Byte
TypeDef Integer = Long

これらは Include\default\Windows.sbp で自動導入されます。

Declare Lib（Win64 API）

Declare Function MessageBoxA Lib "user32.dll" (ByVal hWnd As HWND, ByVal lpText As *Byte, ByVal lpCaption As *Byte, ByVal uType As Long) As Long
Declare Function CreateFileA Lib "kernel32" Alias "CreateFileA" (ByVal lpFileName As *Byte, ...) As HANDLE
Declare Sub RtlMoveMemory Lib "kernel32" (ByVal dest As *Byte, ByVal src As *Byte, ByVal n As Long)
  • Declare Function|Sub 名前 Lib "dll" [Alias "export"] (引数...) [As 型]
  • 対応 DLL: kernel32 / user32 / gdi32 / imm32 / comdlg32 / shell32（.dll 省略可）
  • ByVal = 値渡し、ByRef = アドレス渡し。UDT を API に渡すときはアドレスになることが多い
  • ポインタ引数は *Byte / VoidPtr / HANDLE / HWND など対象幅で書く
  • Long / DWord は 32bit のまま（フラグ・文字数など）
  • SetWindowLong は内部で SetWindowLongPtrA にマップ（64bit）
  • Declare しなくても、コンパイラが知る名前は IAT に載る（下記 WinAPI）

Alias はエクスポート名が Basic 名と違うときに指定します。

呼び出し規則

  • 既定（64bit）: 整数・ポインタ引数は RCX, RDX, R8, R9、以降はスタック。呼び出し側が 32 バイトのシャドウスペースを確保。スタック 16 バイト整列
  • -actba32: stdcall。[esp] から 4 バイトずつ。呼び出し後は callee が pop（ret n）
  • 戻り値は RAX / EAX
Function Add(a As Long, b As Long) As Long
    Add = a + b
End Function

Sub Inc(ByRef x As Long)
    x = x + 1
End Sub

Exit Sub / Exit Function 可。ネストした手続きは不可。戻り値は Function名 = 式。

Class

Class Counter
    Public
    value As Long
    Sub Counter(v As Long)
        value = v
    End Sub
    Sub ~Counter()
    End Sub
    Sub Add(n As Long)
        value = value + n
    End Sub
    Function GetValue() As Long
        GetValue = value
    End Function
End Class

Dim c As Counter(10)
c.Add(32)
x = c.GetValue()
  • Class / End Class。メンバ変数は Type と同様のレイアウト
  • Private / Public（省略時 Private）。Protected は Public 扱い
  • メソッドは暗黙の Me。呼び出しは obj.Method(args)
  • ctor: Sub ClassName(...) → Dim obj As ClassName(args)
  • dtor: Sub ~ClassName() → スコープ脱出時に呼出
  • Inherits / Virtual / vtable は部分対応（COM / D3D11 向け）。p->Release() 可
  • 未対応: New / Delete / Super

Print 式 / Print 式;（CUI）。Input 変数 は String / Long / Byte / Single / Double（stdin 1 行。プロンプト文字列なし）。

End はプロセス終了（コード 0）。#n88basic 時は窓を出して閉じるまで待つ（N88_End）。

演算子

優先（高い順）: As キャスト → ^ → 単項 - → * / \ Mod → + - & → << >> → 関係 → Not → And → Or → Xor。関係の値は真=-1 / 偽=0。

演算意味
+ - *整数。文字列の + / & は連結（同義）
&文字列連結
\ / /整数除算（Long では同義）
Mod剰余
^整数累乗（非負指数）
<< / >>左シフト / 符号付き右シフト
= <> >< < > <= >=比較（値は -1/0。文字列は辞書順）
And / Or / Xorビット演算。条件の And/Or は短絡しうる
単項 - / Not符号反転 / ビット反転
expr As Typeキャスト（Byte/Word は切捨て。String 不可）
+= 等 / ++ --複合代入・インクリメント・デクリメント

実数除算としての / は未対応（整数除算として扱う）。

Math（固定小数点・千分率）

Include\default\Math.abp を常時挿入します。1.0 = 1000。言語の Double 演算（64bit）とは別系統です。

定数値
MATH_ONE1000
MATH_PI3142（π）
MATH_HPI1571（π/2）
MATH_PI26283（2π）
MATH_E2718
Print Sin(MATH_HPI)     ' ≒ 1000
Print Cos(0)            ' = 1000
Print SinDeg(30)        ' ≒ 500

関数: MathDiv / MathMod / Abs / Sgn / Min / Max / Sqr（整数平方根） / Sin / Cos / Tan / SinDeg / CosDeg / Atn / Exp / DegToRad / RadToDeg。 Sin / Cos はマクローリン展開（ラジアン千分率）。

N88BASIC モード

#n88basic / #N88BASIC / #prompt（完全別名）で Include\N88BASIC\n88basic.idx（実体 n88graph.abp）を挿入し、640×480 の黒窓（タイトル N88BASIC）を GUI で開きます。

  • End → N88_End()（窓を表示して閉じるまで待つ）。ソース末尾に N88_Run() も付く
  • LINE / CIRCLE / LOCATE / PAINT が変数代入でないときだけ専用文として解釈
  • LP（最終参照点）を保持。線の終点・円の中心へ更新
LINE (x1,y1)-(x2,y2)[,color][,B|BF]
LINE -(x2,y2)[,color][,B|BF]          ' 始点は LP

省略時の color は 7（白）。B = 四角形の枠、BF = 塗りつぶし四角。

CIRCLE (x,y),r[,color][,start][,end][,aspect][,F[,color2]]
CIRCLE STEP(x,y),r[,...]              ' 中心は LP からの相対
CIRCLE ,r[,...]                       ' 中心は LP
  • 角度はラジアン（小数可。内部は千分率。例: 3.14 → 3140）。省略または start=end で全周
  • 負の角度は絶対値で円弧し、中心から半径線を引く（扇形）
  • aspect は 垂直半径/水平半径（省略時 1.0）
  • F で塗りつぶし（タイルストリングは未対応）
LOCATE x, y
Locate(x, y)          ' 桁 x, 行 y（0 始まり）。以降の Print は窓へ
PAINT (x, y), color1 [, color2]
' color1=塗り色、color2=境界色（省略時 color1）
色01234567
黒青赤マゼンタ緑シアン黄白
#N88BASIC
Locate 0, 0: Print "hello"
Line(40, 40)-(180, 140), 7, B
Paint (50, 50), 2, 7
Sleep(300)
End

N88 の LINE (x)-(y) 文は 32/64 とも同じパーサです。

WinAPI / IAT

名前マップまたは Declare した API がインポートテーブルに載ります。

kernel32: ExitProcess, GetCommandLineA, lstrlenA/lstrcpyA/lstrcatA/lstrcmpA, CreateFileA, ReadFile, WriteFile, CloseHandle, GetFileSize, GetFileAttributesA, GetProcessHeap, HeapAlloc, HeapFree, GetStdHandle, GetModuleHandleA, GetModuleFileNameA, CreateProcessA, WaitForSingleObject, GetExitCodeProcess, GlobalAlloc/Lock/Unlock, RtlMoveMemory, RtlFillMemory, CreatePipe, SetHandleInformation

user32: MessageBoxA, GetMessageA, TranslateMessage, DispatchMessageA, CreateWindowExA, DefWindowProcA, RegisterClassExA, SendMessageA, PostMessageA, PostQuitMessage, DestroyWindow, CreateMenu, CreatePopupMenu, InsertMenuA, SetMenu, TrackPopupMenu, キャレット/クリップボード/InvalidateRect など

gdi32 / imm32 / comdlg32 / shell32: CreateFontA, CreateSolidBrush, CreatePen, SelectObject, TextOutA, Ellipse, Arc, Pie, BitBlt, ImmGetContext, GetOpenFileNameA, ShellExecuteA など

N88 / Sleep 向け: PeekMessageA, MsgWaitForMultipleObjects, GetTickCount

未登録かつ未 Declare の呼び出しはコンパイルエラーになります。

RAD / InsMenu

内部で InsertMenuA を呼びます。hSubMenu <> 0 なら MF_POPUP を付与します。

非対応（意図的）

  • イベント駆動。Class の Inherits / Virtual は部分対応。New / Delete / Super は未対応
  • Single の汎用演算。Double 演算は 64bit のみ（-actba32 は SSE 未実装）
  • GoTo / GoSub / Continue / ReDim / Enum / ネスト手続き
  • 64bit 整数演算（LongLong 算術）
  • リソース（#RESOURCE）埋め込み
